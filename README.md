## 💰 CashTrack AI

**Aplikasi pencatat keuangan pribadi yang sederhana dan modern.**

CashTrack membantu kamu mengelola keuangan harian dengan mencatat pemasukan dan pengeluaran, menetapkan target tabungan, serta menganalisis pola belanja dalam tampilan yang bersih dan responsif.

### ✨ Fitur Utama
- 📊 **Dashboard Real-time**: Lihat total saldo, target tabungan, dan analisis pengeluaran bulan ini
- 💸 **Transaksi**: Catat pemasukan & pengeluaran dengan kategori (Makanan, Minuman, Transport, dll)
- 🎯 **Target Tabungan**: Tetapkan dan pantau progres target keuanganmu
- 🌙 **Dark Mode**: Tampilan nyaman untuk penggunaan malam hari
- 📤 **Ekspor CSV**: Unduh data transaksi untuk backup atau analisis lebih lanjut
- 💾 **Penyimpanan Lokal**: Data disimpan di browser, privasi tetap terjaga

### 🛠️ Tech Stack
- ⚛️ HTML5
- 🚀 Vercel (Deployment)
- 🎨 CSS Modern / Tailwind (diduga)
- 🗄️ LocalStorage (tanpa backend)
